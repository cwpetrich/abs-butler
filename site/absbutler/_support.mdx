## ABS Butler

<Faq>
  <Q q="Where do I report a bug or ask for a feature?">On [GitHub issues](https://github.com/cwpetrich/abs-butler/issues), so the fix and the discussion are public for everyone running it.</Q>
  <Q q="How do I install or update it?">See the [README](https://github.com/cwpetrich/abs-butler#readme). Updating a Docker install is `docker compose pull && docker compose up -d` in its folder.</Q>
  <Q q="Will it change my library without asking?">No. Every operation is a dry run by default, and changing files or metadata each has to be switched on separately in its settings.</Q>
</Faq>
